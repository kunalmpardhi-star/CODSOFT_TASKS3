# CodSoft Task 3 – Password Generator

## 📌 Project Overview

This project is **Task 3 of the CodSoft Python Programming Internship**.

The **Password Generator** is a Python-based application that generates strong and random passwords based on the user's requirements.

## 🚀 Features

* Generate random passwords
* Choose password length
* Include uppercase letters
* Include lowercase letters
* Include numbers
* Include special characters
* Simple and easy-to-use interface

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – Graphical User Interface
* **Random** – Random password generation
* **String** – Character selection

## 🎯 Objective

The main objective of this task is to create a secure and customizable password generator while improving Python programming skills.

## 📚 Learning Outcome

Through this task, I learned:

* Python programming
* Random number and character generation
* String handling
* User input handling
* GUI development using Tkinter
